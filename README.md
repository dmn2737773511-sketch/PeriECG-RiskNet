# PeriECG-RiskNet

The existing PeriECG-RiskNet implementation is in [PeriECG-RiskNet](PeriECG-RiskNet/).

The independent computational study **Event-local assessment of beat-detection reliability in wearable electrocardiography** is in [event-local-reliability](event-local-reliability/). That directory includes installation instructions, wearable-archive numeric reproduction, full public annotated ECG reconstruction, fitted models, result tables and plotting code for the two new supplementary figures. Its detector-failure endpoint and datasets are separate from the original clinical risk model.
