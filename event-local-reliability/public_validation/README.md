# Public annotated ECG computation

This folder implements the prospective computational plan in `FROZEN_PLAN.md`, fixed before inspecting detector outcomes. It evaluates the event-local reliability mechanism on independently acquired, publicly annotated ECG waveforms. It does not validate the fitted three-channel S01 models and is not a clinical validation study.

## Reproduction

Install numpy, scipy, scikit-learn, pandas and wfdb 4.3.0. The creation environment used Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0, scikit-learn 1.8.0 and pandas 2.2.3. The exact Python version and elapsed runtime are recorded in `analysis_summary.json` after execution. WFDB and its dependencies must be installed normally; no vendor folder is distributed.

From the project directory, run `python public_validation/download_public_data.py`, then `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python public_validation/run_public_validation.py`, followed by `python public_validation/summarize_completed_run.py` for the descriptive reporting supplement. The downloader retrieves version 1.0.0 files directly from PhysioNet. `download_manifest.json` records the URLs, byte counts and SHA-256 hashes for all downloaded inputs.

The detector, greedy beat matcher and score are imported unchanged from `run_stress_fixed.py`, copied from the recovered manuscript reproducibility archive. Its checksum and the frozen plan checksum are written to the result summary. The independent target bank preserves all 192 windows; annotations are used only for scoring.

For a numeric refit without downloading waveforms, run `python public_validation/refit_public_models.py --out refit_results` after installing the same dependencies. The supplied features and outcomes reproduce all 141 fitted public models and out-of-fold predictions. The package preflight found byte-identical predictions and parameters, with identical evaluation values.

## Outputs

- `clean_targets.csv`: all clean baseline detector scores, beat counts, lead names and patient groups.
- `annotation_symbol_counts.csv`: reference and non-reference annotation symbols for every target and its scored interval.
- `replay_outcomes.csv`: all 18432 replay episodes, scores and perturbation identifiers.
- `public_replay_banks.npz`: exact filtered target and residual arrays and scoring references, generated by the full run and deliberately omitted from the compact submission package; recreate it from the public source URLs.
- `reliability_features.npz`: 13 global and 6 event features, plus names.
- `residual_invariance.csv`: numerical energy, FFT power and cross-channel covariance checks.
- `heldout_predictions.csv`: out-of-fold predictions from 47 patient groups.
- `fitted_models.json`: train-only scalers and frozen logistic models for each group.
- `model_summary.csv`, `patient_fold_metrics.csv`, `risk_coverage.csv`, `fixed_threshold_retention.csv`, `calibration_bins.csv`: reliability evaluation.
- `matched_quartets.csv`, `quartet_summary.csv`: label crossings, invariant bounds and pair concordance.
- `outcome_summary.csv`: outcomes by perturbation ratio and noise type, including the prespecified clean-primary-success subset.
- `fit_warnings.json`: any numerical convergence warnings, retained without adjustment.
- `fixed_threshold_by_patient.csv`, `fixed_threshold_source_counts.json`: the prespecified risk policy by patient and by clean baseline status, including excluded nonfailures.
- `descriptive_verification.json`, `patient_equal_metric_summary.csv`, `source_holdout_checks.json`: input totals, clean baseline summaries, patient-equal model summaries and explicit source checks.

## Attribution and scope

MIT-BIH Arrhythmia Database v1.0.0 and MIT-BIH Noise Stress Test Database v1.0.0 are from PhysioNet and distributed under the Open Data Commons Attribution License v1.0. Dataset URLs and recommended original citations are in `SOURCES.json`. PhysioNet dataset DOIs are 10.13026/C2F305 and 10.13026/C2HS3T.

The target patient is absent from each training fold; records 201 and 202 are bound to one patient group. The fixed six noise windows are intentionally reused across folds. Thus the evaluated condition is an unseen target patient under a known benchmark perturbation bank. The correlated replay episodes are not treated as independent patients or as independent inferential observations.
